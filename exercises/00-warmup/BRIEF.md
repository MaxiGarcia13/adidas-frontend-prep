# 00 — Warmup

**Timebox:** ~5 minutes  
**Goal:** Confirm your local React/TypeScript toolchain works before a timed session.

## Tasks

1. `pnpm install` and `pnpm dev` in this folder.
2. Open the app in the browser.
3. Click the button and confirm the counter increments.
4. Make a tiny visible change (e.g. rename the heading) and see HMR update.

## Done when

- Dev server runs without errors.
- You can edit and see updates.
- You are ready to start a real exercise with the coach.
